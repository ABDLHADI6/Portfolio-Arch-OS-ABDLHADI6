Lab 4: HTML, CSS and JavaScript Basics

Lab Overview

In this lab, I organised my portfolio by creating separate CSS and JavaScript files and linking them to my HTML. I added individual HTML pages for each lab, moved my lab content into those pages, and kept my index.html as a clean landing page with a welcome message. I then styled the page using CSS with tag selectors and class selectors (like .name and .description), and used JavaScript to access those classes via querySelector and log them to the console. I also added a navigation system using a list of links, then improved it into a proper navigation bar. Finally, I implemented a Dark Mode toggle with a button, CSS classes for dark styles, and JavaScript event listeners to switch between light and dark themes across the portfolio.
