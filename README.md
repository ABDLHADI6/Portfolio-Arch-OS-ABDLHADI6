# Portfolio-Arch-OS-ABDLHADI6
An academic portfolio documenting 8 laboratory tasks for the ARCHOSC module (Architectures, Operating Systems, and the Cloud).

## Repository Structure

The following tree represents the current organization of the project:

```text
.
├── .github/workflows/      # CI/CD deployment configurations
├── Pictures/               # Assets and screenshots for documentation
├── CICD1.html              # Continuous Integration lab part 1
├── CICD2.html              # Continuous Integration lab part 2
├── GithubInformation.txt   # Reference notes for GitHub usage
├── HTML_CSS_JS.html        # Web fundamentals overview
├── Introductory Lab.html   # Initial setup and basic concepts
├── Memory.html             # OS Memory management simulation/notes
├── README.md               # Project documentation (this file)
├── Resource.html           # Resource management and allocation
├── Scheduling.html         # CPU Scheduling algorithms and reference
├── VM1.html                # Virtual Machine/Memory concept lab 1
├── VM2.html                # Virtual Machine/Memory concept lab 2
├── index.html              # Main entry point for the web dashboard
├── script.js               # Global JavaScript logic
└── style.css               # Global stylesheet for all HTML pages
```

# Key Components

## 1. Web Development Core
- `index.html`: The central landing page that connects all labs.
- `style.css` and `script.js`: Shared resources that provide a consistent look and interactive functionality across the project.

## 2. Operating System Labs
- `Scheduling.html`: Detailed breakdown of scheduling concepts (linked to the C# code references).
- **Memory and VM Labs**: Exploration of how systems manage physical and virtual memory.

## 3. CI/CD Integration
- **CICD Labs**: Documentation and implementation of automated workflows.
- `.github/workflows`: Contains the YAML files for GitHub Actions to automate deployment.

# Tech Stack
- **Frontend**: HTML5, CSS3, JavaScript
- **Backend/Logic**: C# (Snippets provided in relevant lab sections)
- **DevOps**: GitHub Actions for CI/CD

# How to Use
1. Clone the repository.
2. Open `index.html` in any modern web browser to navigate through the different labs.
3. Use the **Back to Scheduling** buttons within specific sub-pages to return to the main scheduling module.
